# 00 · 总览

从「刚买了一台 VPS / NAT 小鸡」到「节点进订阅、三端可用、有据可查、可回滚」，一套可照着走的流程。适用于几美元一月的低价 NAT 容器，也适用于正规 VPS。

本仓是**工作流**：文档 + 脚本 + 模板。真实机器的凭据、IP、订阅令牌不在仓里（`private/` 整块不上传）。

## 先看这张表：这机器值不值得留

上架到一半决定留还是退，只看两件事，**分开测**。

| TCP（大陆侧直连） | UDP（入站可达） | 结论 | 干什么 |
|---|---|---|---|
| 通 | 通 | **双协议上架** | Reality 保底 + Hysteria2 主力 |
| 通 | 不通 | **单协议上架** | 只上 Reality（或 WS） |
| 不通 | 通 | **单协议上架**（别退货） | 只上 hy2；Reality 砍掉，不加直连规则 |
| 不通 | 不通 | **退货** | 留证据 → 找平台 |

两个真实教训支撑这张表：

- 只测 TCP 就判「废机」，会白扔一台 hy2 实测 **6.7–7.9 MB/s**、比同价位大多数机器都快的机器——它的 UDP 完全没被封。
- 只测 UDP 就高兴上架，会在装完 sing-box、验完计数、跑完测速之后才发现大陆侧 TCP 全端口不通——白做一轮工。

所以：**先测，再装**。见 [01-开工前](01-开工前：先测什么.md)。

## 四台机器，四个角色

| 角色 | 干什么 | 要求 |
|---|---|---|
| **目标机** | 被上架的 VPS / NAT 小鸡 | 有 ssh、平台给端口映射 |
| **工作机**（`<sender>`） | 下载校验二进制、流式传送、外部 vantage 验证、跑客户端冒烟 | 能直连 GitHub；建议不在透明代理下 |
| **订阅生成机**（`<subhost>`） | 生成 mihomo 配置并分发 | 任意一台有 443 的小机器，只发文件不过流量 |
| **出口侧客户端** | 路由器 OpenClash / 手机 / PC | 支持 mihomo 内核 |

只有目标机是必须的。一个人自用可以跳过订阅生成机，直接拿 `client-test.json` 当客户端配置。

## 架构（三层，数据不过中间层）

```
订阅生成机 <subhost>:/opt/sub-gen/
   模板 + 私有节点清单 → mihomo -t 校验 → 原子发布
                │
                ▼
分发  https://<你的域名>/<令牌>/sub.yaml     ← 静态只读，只发配置
                │
       ┌────────┴─────────┬──────────────┐
   路由器 OpenClash      手机            PC
       └──── 拉完直连节点，流量不经中间机 ────┘
```

订阅链接里的令牌是可吊销凭据：对外分发场景使用**独立令牌**，不与主令牌混用。

## 五条原则

1. **先测后装**：形态由实测决定，不由面板描述决定。
2. **判通只认协议级 + 外部视角**：透明代理下本机 `nc` 对任意境外 IP:端口都假 OPEN。用 `curl --resolve`、客户端冒烟、容器 `ss`。
3. **私钥不出服务器**：Reality 私钥只写目标机 `/etc/sing-box/config.json`（600），交付文件只留 UUID / 公钥 / short_id。
4. **三层一致**：生成物 → 分发文件 → 客户端实际生效，sha 对得上才算完。
5. **任何改动都能回滚**：先备份、留一条可粘贴的回滚命令，再动手。

## 术语

| 词 | 含义 |
|---|---|
| `<name>` | 节点基名，全小写短名。各形态 `<name>` / `<name>-hy2` / `<name>-cf` |
| `<sender>` | 工作机，也是外部 vantage：从外面往回打，判断服务端真的在听 |
| `<subhost>` | 跑订阅生成器的机器 |
| Reality | TCP 伪装型协议，抗封锁好，需要借用一个真实站点的 SNI |
| hy2 | Hysteria2，基于 QUIC/UDP，丢包线路下快，但对共享母鸡要加固 |
| park / dead | 订阅里的两种摘除标记：`# park` 整条不渲染；`# dead` 仍下发但摘出自选组 |
| 三层一致 | 生成物 sha == 线上 sha == 客户端实际生效 |
