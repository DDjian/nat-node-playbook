# 05 · 坑表

按「症状」查。每条给原因和修法，不写故事。

## 连通性判断

| 症状 | 原因 | 修法 |
|---|---|---|
| 本机 `nc -z` 任意境外 IP 都 OPEN | 工作机挂透明代理，代理先握手 | 用 `curl --noproxy '*'`，先确认 `icanhazip` 回显是本地出口 |
| `ping` 通，端口连不上 | ICMP 与 TCP 走不同策略 | 只认 TCP/UDP 实测，别用 ping 判断可用性 |
| 面板已放行，外面连不上 | 上层链路过滤，或映射写错 | 从外部 vantage 用三个端口各测一次，隔 10 分钟复测 |
| 只有自己的机器连不上 | 本地 DNS/规则/tun 干扰 | 换一台完全没装客户端的机器复测 |
| 延迟 0.1ms 很漂亮 | 内核探活命中了本地直连 | 看 `/proxies` 的 `now` 与真实 `curl` 出口 IP |
| TCP 全封就判定「废机」 | 只测了 TCP | 单独测 UDP：可能有机器 UDP 完全放行、hy2 能跑到 7MB/s 以上 |
| UDP 通就直接上架 | 没测大陆侧 TCP | 两条链路都要测，否则装完才发现 TCP 不通，白做一轮 |

## 二进制与运行

| 症状 | 原因 | 修法 |
|---|---|---|
| `sing-box: not found` / `Exec format error` | Alpine 是 musl，装了 glibc 版本 | 下载 `-musl` 变体；`ldd --version` 先确认 libc |
| 目标机 `curl github.com` 超时 | 容器出站受限 | 在工作机下载校验，**流式**传二进制过去（`ssh 'cat >' < file`） |
| 传过去能跑但版本异常 | 流被截断 | 两侧 `sha256sum` 对账，不一致就重传 |
| `sing-box check` 报 JSON 错 | 尾逗号 / 注释 / 占位符没替换完 | 用 `jq . config.json` 先过一遍语法 |
| `address already in use` | 平台预装服务占了端口 | `ss -lntup` 找占用者；换端口或停旧服务 |
| 服务起来了但重启后没了 | 没做 `rc-update add` / `systemctl enable` | 加自启，并 `pkill -9` 实测 6 秒内自愈 |
| 进程莫名消失 | cgroup 限额被 page cache 顶满 → OOM | 看 `memory.stat` 的 `anon`；装 mem-reclaim；见下节 |
| SSH 突然连不上、机器还在 | 改配置时把自己锁在外面 | 改动前留一个已登录会话；先 `sing-box check` 再重启；端口变更用 `socat`/备用端口过渡 |

## 内存与容器

| 症状 | 原因 | 修法 |
|---|---|---|
| `free` 显示还有内存但进程被 OOM kill | `free` 看的是宿主，cgroup 看自己的限额 | 只认 `/sys/fs/cgroup/memory.max` 与 `memory.stat` |
| 写文件多之后服务崩 | page cache 计入 cgroup，被算成「已用」 | `echo 10M > /sys/fs/cgroup/memory.reclaim` 多次回收 |
| 回收后立刻又满 | 只回收文件缓存，anon 在持续涨 | 降连接数 / 降带宽；换更大的机器 |
| 压测后容器整个失去响应 | 1C/1G 跑 30Mbps hy2 超出承载 | 低价机按轻量自用设计，别跑长连接大流量 |
| 容器 swap 涨到 20MB+ | 连写大文件触发匿名页回写 | 只跑代理，别在同机编译/打包 |

## 协议与性能

| 症状 | 原因 | 修法 |
|---|---|---|
| Reality 握手超时 | SNI 借的站点不可达，或 `short_id` 不匹配 | 换一个稳定 SNI（同机房延迟低的大站）；核对客户端 `short_id` |
| Reality 能连但马上断 | `server_name` 与证书链不符 | 用该站点真实支持的域名，别乱填 |
| hy2 连不上 | UDP 没放行 / obfs 口令错 / 客户端填了 up-down | 三项逐个排；共享母鸡必须 `ignore_client_bandwidth: true` |
| hy2 很快但母鸡被投诉 | Brutal 无视带宽持续灌包 | 服务端 `ignore_client_bandwidth: true`，客户端不填 up/down |
| 同一机器 TCP 0.3 MB/s、UDP 4 MB/s | TCP 丢包降窗，hy2 不降速 | 丢包线路优先 hy2，Reality 作保底 |
| 晚高峰速度腰斩 | 出口拥塞 | 用 `-cf` 形态或换机房；这不是配置问题 |
| CF 隧道速度只有几百 KB/s | 免费版限速 | 当保底通道，不做主力；订阅里把 `-cf` 摘出视频组 |

## 订阅与客户端

| 症状 | 原因 | 修法 |
|---|---|---|
| 本机自测必失败，手机却正常 | 缺 `IP-CIDR,<节点IP>/32,DIRECT,no-resolve` | 加直连规则；只放 UDP 的机器不要加 |
| 新形态漏进对外分发档 | 排除清单按精确名匹配 | 改成按**形态前缀展开**（排 `node-a` 连带 `node-a-cf`） |
| 拉到的 sha 与服务器不一致 | 反代/CDN 缓存旧文件 | `Cache-Control: no-store`，或文件名带版本号 |
| mihomo 报 `duplicate group name` | 拼接组块时块尾判定错，新旧组并存 | 用 `splice-runtime-groups.py`；块尾判定要排除顶格 `- ` 列表项 |
| 删掉的节点还在列表里 | 只换了 proxy-groups，没换 proxies 块 | 两块一起换 |
| 改名后兜底脚本静默失效 | 脚本硬编码了旧节点名，API 返回 400 | 改成按前缀动态发现；改名前 `grep -r` 一遍 |
| `clash_meta -t` 报 `SAFE_PATHS` 错 | 运行态配置里有 `external-ui` 绝对路径 | 拉到独立目录、`sed` 掉该行再校验；`SAFE_PATHS` 用空格分隔 |
| 客户端改了选择又被改回去 | `store-selected` + 自动脚本覆盖 | 查自动选点脚本与 crontab；手动选择应持久 |
| 订阅令牌泄漏 | 分发场景混用主令牌 | 按分发场景使用独立令牌、随时吊销；令牌不进聊天与文档 |

## 流程与协作

| 症状 | 原因 | 修法 |
|---|---|---|
| 装完发现该退 | 没先测 TCP/UDP | 拿到机器先做 [01](01-开工前：先测什么.md)，15 分钟定生死 |
| 退款被驳回 | 只有口头描述 | 三份证据：服务在听 + 面板映射 + 外部三次失败输出 |
| 过窗口才发现不能用 | 退款期限 24–72h，测试拖了几天 | 第一小时内测完；过窗口改成 hy2-only 或别的用途 |
| 凭据出现在文档/聊天里 | 交付时顺手复制了私钥 | 私钥只留服务端配置（600）；交付只写 UUID/公钥/short_id |
| 两台机器配置互相覆盖 | 用了同一个 `<name>` | 一台机器一个目录名，形态用后缀区分 |
| 平台警告 / 清退 | NAT 平台限制高流量共享用途与长期满载 | 按个人轻量用途配置；对外分发场景使用独立令牌档位 |
| 改动后不知道改了什么 | 没留痕 | 每次变更一条记录：备份路径 + 语义 + 回滚命令 |
