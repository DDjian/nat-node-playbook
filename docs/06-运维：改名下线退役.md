# 06 · 运维：改名、下线、退役

机器会到期、会变慢、会被平台清退。这一章是「用久了之后」的动作。

## 改名（最危险，四处契约）

改一个节点名，要同时改四个地方，漏一处不报错、只静默失效：

1. **节点清单**：`nodes.private.yaml` 的 `- name:` → `python3 gen.py` 重新生成；
2. **路由器两份文件**：订阅原件（`/etc/openclash/config/<名>.yaml`）+ 运行态（`/etc/openclash/<名>.yaml`）。只改运行态，重启会带回旧名；
3. **硬编码该名字的脚本**：兜底切换、白名单、自愈脚本。改名前先 `grep -rn '<旧名>' /etc/openclash/` 一遍；
4. **对外档位的显式名单**（如 `AI`）。引用了不存在的节点会被生成器自检拦下，整批不发布——这是保护，别绕过。

改完：客户端重拉订阅，`/proxies` 确认新名在列；旧名的选择记忆会失效，手动组会落回自动组，提醒使用者。

## 暂时下线 vs 彻底退役

| 动作 | 怎么做 | 回滚 |
|---|---|---|
| **暂时下线**（机器在、不想用） | 节点块上方加 `# park: 原因` → 重新生成 | 删掉那行注释 |
| **不稳定但仍想留着** | 加 `# dead`（仍下发，摘出自动组） | 删标记 |
| **带宽不够** | 加 `# low-bw: 10M`（摘出视频组） | 删标记 |
| **彻底退役** | 见下面「退役清单」 | 从归档恢复目录 |

`# park` 而不是删块：删了要恢复就得手工重写整段配置，park 只删一行。

## 退役清单

1. **停止服务**：`rc-service sing-box stop && rc-update del sing-box`（systemd 对应 `systemctl disable --now`）；
2. **撤销入站**：平台面板删端口映射；CF 隧道删除 DNS 记录并 revoke token；
3. **吊销凭据**：订阅里移除条目；如用过独立令牌，吊销它；
4. **落档**：节点目录整体移到 `archive/<name>/`，`archive/README.md` 里加一行（名字、起止日期、退役原因）；
5. **改订阅**：按「改名/下线」流程，三层一致后通知使用者重拉；
6. **留痕**：变更记录一条，写清「谁在用、切到哪去了」。

退役后**不要**立刻删目录。留 1–2 个月，等确认没有别处还在引用（尤其是客户端里残留的手动选择、路由器上某个脚本）。

## 到期与续费

在台账里给每台机器记两个日期：**购买/开通**、**到期**。到期前一周看两件事：

- 这台机器现在还有流量吗？（`/proxies` 的 `now`、路由器连接数、订阅里客户端是否还在用）
- 有没有已经由别的机器覆盖它的角色？

两个都否 → 不续。续了放着不用，等于每月付钱养一个 IP。

## 退款 / 早退

超出售后期、或机器质量不达标但退不了：

1. 先按 [01 步骤 6](01-开工前：先测什么.md) 收证据（服务在听 + 面板映射 + 外部失败输出）。**证据要当场收**，过期补不出来；
2. 走平台工单，一次说清三件事：现象、已排除项、诉求（修 / 换 / 退）；
3. 退不了就改用途：只跑 hy2（如果 UDP 通）、当跳板、当备用出口、当 DNS 前端。别为了「回本」继续堆服务。

## 每月花 10 分钟

- `/proxies`：有没有节点长期 `now` 落空、延迟异常；
- 台账：到期日、流量用量、平台有没有新条款；
- 订阅：三层 sha 是否仍一致（防止某次手工改动漂移）；
- 日志：`grep -c panic`、磁盘余量、`memory.stat` 的 `anon` 趋势。

## 变更记录怎么写

```
## 2026-11-17 · <name> 加入订阅
备份：<备份目录>
语义：新增一台 <形态>，进 Proxy/Proxy-Auto，不进 AI
验证：三层 sha 一致 <前12位>；路由器 /proxies 可见；curl 出口 = <name> IP
回滚：<一条可粘贴的命令>
```
